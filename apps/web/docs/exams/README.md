# Exam Management Module — SentinelAI

## Overview
The Exam Management module provides comprehensive assessment authoring, section builders, candidate roster whitelisting, schedule window controls, browser lockdown policies, AI computer vision proctoring rules, and candidate experience simulation.

## Included Pages & Routes
- `/dashboard/exams`: Primary exam directory with search, filter toolbar, and bulk action triggers.
- `/dashboard/exams/new`: Exam creation wizard.
- `/dashboard/exams/[id]`: Exam specification detail hub.
- `/dashboard/exams/[id]/edit`: Parameter editor.
- `/dashboard/exams/[id]/sections`: Multi-section timer & weighting builder.
- `/dashboard/exams/[id]/schedule`: Start/end window & grace period setup.
- `/dashboard/exams/[id]/instructions`: Candidate honor code instructions editor.
- `/dashboard/exams/[id]/eligibility`: Department & candidate email whitelist selector.
- `/dashboard/exams/[id]/security`: Browser lockdown & environment integrity rules.
- `/dashboard/exams/[id]/proctoring`: AI computer vision & acoustic sensitivity parameters.
- `/dashboard/exams/[id]/preview`: Candidate test-taking simulation preview.
- `/dashboard/exams/[id]/analytics`: Score distribution & participation metrics.
