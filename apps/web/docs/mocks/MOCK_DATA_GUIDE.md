# Mock Data Guide — SentinelAI

## Included Datasets
- **Dev Users**: Super Admin, Institution Admin, Faculty, Proctor, Student.
- **Institutions**: Institutions, Departments, Courses, Programs, Batches.
- **Exams**: 15+ exams with Draft, Published, Scheduled, Live, Completed, and Archived states.
