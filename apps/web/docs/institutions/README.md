# Institution Management Module (`@sentinel-ai/web/institutions`)

The **Institution Management Module** provides full multi-tenant institution provisioning, department management, course catalogs, faculty assignments, cohort batches, portal branding, and proctoring security configurations.

---

## Features

- **Full Lifecycle CRUD**: Provision, update, suspend, or archive institutions.
- **Sub-Resource Management**: Manage departments, courses, faculty staff, programs, and cohort batches.
- **Portal Branding Engine**: Custom logos, favicons, primary/secondary brand colors, and subdomain routing.
- **Proctoring Sensitivity Policies**: Configure security levels (`STRICT`, `STANDARD`, `LOW`, `CUSTOM`), mobile assessment access, and IP whitelists.
