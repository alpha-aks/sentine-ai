# Institution Component Reference

## 1. `InstitutionTable`
Tabular component with checkbox selection, status badges, and action dropdowns.

## 2. `InstitutionForm`
RHF + Zod validated form for provisioning and updating institutions.

## 3. `BrandingEditor`
Portal logo URL, color picker, and custom subdomain preview editor.

## 4. `SettingsPanel`
Security thresholds, IP whitelists, and SAML SSO integration settings.
