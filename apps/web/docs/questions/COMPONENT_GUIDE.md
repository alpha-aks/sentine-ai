# Component Guide — Question Bank Module

- `QuestionTable`: Master table displaying prompt title, body snippet, type badge, difficulty badge, marks, status badge, and action dropdown menu.
- `QuestionCard`: Grid view card component for question bank items.
- `QuestionEditor`: Dynamic form editor for text prompts, MCQ choice lists, marks, negative penalty marks, and explanations.
- `CodeEditor`: Code problem configuration tool for target programming languages and starter code stubs.
- `QuestionPreview`: Candidate simulation interface supporting all 11 question types.
- `QuestionPoolEditor`: Pool creation form for specifying pool name and target draw count.
- `CategoryManager`: Subject category taxonomy management.
- `TagManager`: Tag label manager.
- `TypeBadge` / `DifficultyBadge` / `StatusBadge`: Styled tags for metadata.
- `FileUploader`: Drag & drop file selector for question imports.
- `ImportPreview`: Import file schema validation table.
