# Question Type Guide — Question Bank Module

The Question Bank module supports 11 question types:

1. `MCQ_SINGLE`: Multiple Choice (Single correct answer option)
2. `MCQ_MULTIPLE`: Multiple Choice (Multiple correct answer options)
3. `TRUE_FALSE`: True / False binary evaluation
4. `FILL_BLANK`: Fill in the blank text entry
5. `SHORT_ANSWER`: Short text string answer
6. `LONG_ANSWER`: Multi-paragraph essay response
7. `NUMERICAL`: Numeric value with optional error tolerance
8. `CODE_SNIPPET`: Code programming problem with starter code stub and language selection
9. `FILE_UPLOAD`: File attachment submission (PDF, DOCX, ZIP)
10. `MATCHING`: Key-value pair matching
11. `ORDERING`: Sequential item ordering
