# Question Bank Module — SentinelAI

## Overview
The Question Bank module enables authoring, reviewing, organizing, and pooling multi-format examination questions across 11 formats. It includes code problem configuration, category and tag taxonomies, batch import/export, and candidate simulation previews.

## Included Pages & Routes
- `/dashboard/questions`: Master question bank directory with search, filter toolbar, and taxonomy links.
- `/dashboard/questions/new`: Multi-format question authoring wizard.
- `/dashboard/questions/[id]`: Question detail view with prompt text, choice options, and approval status.
- `/dashboard/questions/[id]/edit`: Question editor for prompts and options.
- `/dashboard/questions/import`: CSV, JSON, Markdown, Excel batch import tool.
- `/dashboard/questions/export`: Question export generator.
- `/dashboard/questions/pools`: Dynamic random selection pool manager.
- `/dashboard/questions/categories`: Category taxonomy manager.
- `/dashboard/questions/tags`: Tag taxonomy manager.
- `/dashboard/questions/preview`: Candidate test-taking interface preview.
