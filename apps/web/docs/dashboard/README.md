# SentinelAI Admin Dashboard Shell (`@sentinel-ai/web/dashboard`)

The **Admin Dashboard Shell** provides the foundation layout and global component infrastructure for all SentinelAI administration, proctoring, analytics, and tenant management sub-routes.

---

## Key Features

- **Responsive Shell Layout**: Persistent collapsible sidebar, top navbar with quick search, breadcrumbs, content container, and theme switcher.
- **High-Density Metrics Cards**: `StatsCard`, `QuickActionCard`, `SystemHealthCard`, `RecentActivityCard`.
- **System Health Monitor**: Real-time health status tracking across all 7 microservices (Ports 4001–4007).
- **Cmd/Ctrl+K Quick Search**: Global command palette for feature navigation.
- **Fullscreen Mode**: One-click fullscreen toggle using Browser Fullscreen API.
