# Component Guide — Candidate Portal Module

- `ExamLayout`: Distraction-free full-screen layout container.
- `QuestionRenderer`: Unified renderer for 11 question input formats.
- `QuestionPalette`: Sidebar grid showing Answered, Unanswered, Marked for Review, and Current question statuses.
- `QuestionNavigator`: Sidebar container for QuestionPalette.
- `CandidateTimer`: Countdown timer with low-time warning alerts.
- `CameraStatus`: Live webcam preview and stream diagnostic component.
- `MicrophoneStatus`: Live microphone audio level meter.
- `ConnectionStatus`: Real-time online/offline indicator and reconnect state.
- `ViolationBanner`: High-priority proctoring alert bar.
- `FullscreenBanner`: Fullscreen lock modal when full-screen focus is lost.
- `ExamHeader`: Top navigation header during exam.
- `ExamFooter`: Bottom controls for Previous, Next, Mark for Review, and Clear Answer.
- `SubmissionDialog`: Final confirmation modal with response counts.
- `ReviewPanel`: Response status progress summary cards.
- `LoadingScreen`: Secure environment loading component.
- `SystemCheckCard`: Diagnostic pass/fail summary list.
- `WaitingRoomCard`: Pre-exam schedule card.
