# SentinelAI User & Role Management Module

## Overview
The **User & Role Management Module** provides enterprise access control, multi-tenant role assignments, granular permission matrices, and onboarding invitation workflows for SentinelAI.

---

## Features

- **User Accounts Directory**: Search, filter, bulk selection, account status toggles (`ACTIVE`, `INACTIVE`, `SUSPENDED`, `DEACTIVATED`).
- **Role Matrix Management**: View and edit permission sets for `EXAM_ADMIN`, `PROCTOR_SUPERVISOR`, `LIVE_PROCTOR`, `COMPLIANCE_OFFICER`, and `CANDIDATE`.
- **Granular Permission Overrides**: Grant or revoke specific permission keys per individual user.
- **User Invitations**: Onboarding email invitations with token expiration tracking and cancellation.
- **Responsive UI & State Management**: Zustand UI store for real-time search, filters, pagination, and modal triggers.
